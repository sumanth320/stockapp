# stockapp
Project to create a stock tracker app using Microservices architecture. We are decoupling UI touchpoint and the API hits separately using Redis cache to track the tickers and update the prices. This is a basic UI setup primarily focusing on the Mircoservices architecture. The next project will focus primarily on using Orchestration and K8s.

The API Key for the AlphaVantage needs to be updated with your own key in worker.py
